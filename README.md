# Sprint 7 - Aplicación Web con Streamlit

Este proyecto desarrolla una aplicación web interactiva para explorar un conjunto de datos de anuncios de venta de coches.

La aplicación crear de forma interactiva los siguientes graficos:

- Un histograma de la distribución del odómetro.
- Un gráfico de dispersión entre odómetro y precio.

La app fue construida con Python, pandas, plotly y Streamlit, y desplegada en Render.
